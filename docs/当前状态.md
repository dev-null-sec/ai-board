# 当前状态

> 给下一次 AI 或人类开发者快速接上上下文用。保持短、准、新。

## 项目一句话

`ai-board` 是一个轻量本地 CLI，用 JSON 作为唯一真相源，为 AI 协作开发提供任务入池、排期、claim、验收、归档和冲突检查。

## 当前能力

- 已创建 Python 包结构：`src/ai_board/`。
- 已实现 CLI 命令：`init`、`add`、`schedule`、`start`、`complete`、`archive`、`block`、`status`、`conflicts`、`render`、`show`。
- 已新增 `onboard` 命令，用于 AI 首次接手项目时检测空项目、轻量新项目或已有项目，并输出下一步询问和接手建议；支持 `--init-if-missing`。
- 已补充 `goal` 命令，用于从结构化数据设置当前目标。
- 已补充 `skills list`、`skills get core`、`skills get core --full`，用于让 AI 从 CLI 读取版本匹配的使用说明。
- 已新增 `skills/ai-board/SKILL.md` discovery stub，预设 GitHub 安装地址 `https://github.com/dev-null-sec/ai-board.git`，安装策略为先检查已有命令，再优先走 Python 3.10+ / pipx 用户级安装，最后才用 `uv tool` 兜底；README 和 guide 已说明还需要把 skill 文件放到 Codex、Claude 等目标 agent 的 skill/skills 目录。
- 已实现 `.ai-board/board.json` 读写。
- 已新增 `.ai-board/events.jsonl` 事件日志：`add`、`schedule`、`start`、`complete`、`archive`、`block`、`renew`、`unlock`、`goal` 等写操作会追加结构化事件；事件写入失败不会阻断 `board.json` 主流程。
- 已新增 `history [TASK_ID]` 命令，可读取 `.ai-board/events.jsonl` 查看全部事件或单个任务历史；事件日志缺失、为空或损坏时会给出清楚提示。
- `load_board` 已增加基础 schema 校验和字段补全：旧 board 缺少 `agents`、`lane`、`acceptance`、`depends_on`、`scope` 等字段时会补默认值，损坏 JSON 或不支持的 schema 会给出可读错误。
- 已实现 `docs/计划看板.md` 和 `docs/归档计划看板.md` 自动渲染；当前看板各栏目内按优先级 P0、P1、P2、P3 排序显示。
- `ai-board init` 已 CLI 化 `ai-native-project-init` 的核心能力：会生成 `AGENTS.md`、开发规范、当前状态、决策记录、项目方向、页面设计、项目路线等 guardrail 文档；已有文档默认写 `.example`，不覆盖。
- 已实现基于 active task scope 的简单冲突检测；过期 scope lock 会被冲突检查忽略。
- task scope 已做路径规范化和校验：反斜杠、重复分隔符、`.`、等价相对路径会统一处理，绝对路径和跳出项目根的 `..` 会被拒绝。
- 已实现本地 board 写入锁和原子替换，降低多进程同时写 `.ai-board/board.json` 时损坏 JSON 的风险。
- `board.lock` 已写入 JSON 元数据，包含 pid、创建时间和命令信息；写操作遇到过期或无效 lock 时可自动清理，降低进程崩溃后锁残留导致 CLI 不可写的风险。
- Windows 并发写入下，如果 stale lock 正被另一个进程占用，清理会继续等待而不是直接崩溃。
- `doctor` 已扩展为完整项目自检：会检查 stale board lock、board schema、active task 的 owner/scope、agent 身份状态、scope 冲突、生成看板是否过期，以及事件日志是否可读。
- 已实现 agent 身份池：`agents claim --kind codex` 会分配 `codex-00`、`codex-01` 等身份，`agents list` 可查看 idle/busy/expired，任务 `complete` 后自动释放身份，`archive` 作为旧数据兼容兜底。
- `start` 默认阻止与未过期 active task scope 重叠的任务，支持 `--force` 显式覆盖；scope lock 默认 240 分钟租约，`locks` 可查看 active/expired 状态，`renew` 可续租，`unlock` 可手动释放 scope。
- 任务已支持 `lane`、`source`、`acceptance`、`depends_on` 字段；`add` 可通过 `--lane`、`--source`、重复 `--acceptance`、`--depends-on` 写入，并会校验依赖存在、自依赖和简单循环；`start` 默认阻止依赖未完成的任务，可用 `--force` 显式放行。
- 任务状态转换已集中校验：`schedule`、`start`、`complete`、`archive`、`block` 都只能从允许状态进入，避免绕过生命周期规则。
- 计划看板在每个状态栏目内支持按 lane 分组显示，保持一个 board.json 和一个执行入口。
- 已补充发布 Logo、MIT LICENSE，并重写中英文 README。
- 已创建 `examples/demo-project` 示例项目并跑通过一次完整生命周期。
- 已补充端到端测试：覆盖真实测试项目 onboarding 到归档的完整流程，以及两个 codex agent 并行协作、scope 冲突阻止、完成释放和身份复用。
- 项目自身已接入 `.ai-board/board.json`，并用本 CLI 驱动当前任务、看板渲染和归档。

- Python 3.10+
- 标准库：`argparse`、`json`、`pathlib`、`unittest`
- 打包：`setuptools`
- 运行期无第三方依赖

- Markdown 是生成视图，后续需要在 README 和规则中反复强调不要手改生成看板。
- 冲突检测只覆盖路径重叠，不做语义级代码冲突判断。
