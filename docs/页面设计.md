# 页面设计

> 前端、应用、工具类项目可使用；非前端项目可以忽略或删除。

## 设计目标

当前 v1 是 CLI-only 项目，暂不做 Web UI。本文件用于记录未来可视化看板方向，避免临时起意时偏离 CLI 最小闭环。

## 页面清单

- 暂无已排期页面。
- 候选：本地 Web/TUI 看板，展示 Inbox、Scheduled、Active、Done、Archive 和冲突提醒。

## 核心流程

- 用户或 AI 通过 CLI 写入 `.ai-board/board.json`。
- 可视化界面只读取同一个 JSON 源。
- 所有状态变更仍通过受控命令完成，不在 UI 里绕过状态机。

## 视觉与交互约束

- 偏开发工具风格，信息密度高，避免营销页式大卡片。
- 清晰显示任务状态、负责人、scope、验收结果和冲突。
- 冲突和阻塞应该有明显标识。

## 验收标准

- v1 不验收页面。
- 未来若做 UI，必须能准确反映 JSON 状态，不产生第二套真相源。
