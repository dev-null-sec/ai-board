# 项目路线

> 长期方向放这里。注意：路线不是当前开发指令，`docs/计划看板.md` 才是当前执行依据。

## 路线列表

- v0.1：本地 CLI + JSON 唯一真相源 + Markdown 渲染。
- v0.2：更完善的开源发布体验，包括 LICENSE、安装说明、更多示例和命令文档。
- v0.3：多 agent 协作增强，包括任务 lease、超时释放、依赖检查和更清楚的冲突报告。
- v0.4：可选事件日志和历史查询，保持 `board.json` 为默认真相源。
- v0.5：可选可视化界面；SQLite 仅在任务量、复杂查询或跨项目聚合需求明确后再评估。

## 使用规则

- 新路线可以新建独立 Markdown 文件。
- 路线变化需要同步 `docs/计划看板.md` 的优先级。
- 重要方向取舍需要记录到 `docs/决策记录.md`。
